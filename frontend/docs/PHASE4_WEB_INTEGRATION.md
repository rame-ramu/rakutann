# PHASE 4: 既存Webアプリ統合

検証日: 2026-08-21

- 旧378クラスの固定配列を正式Excel由来の6,298クラスへ置換した。
- 学生プロフィールによる履修候補フィルタを、既存推薦・検索処理の前段へ追加した。
- 評価、試験、レポート、出席、オンデマンド、グループワーク、教員、曜日時限、
  授業詳細、推薦スコア、時間割処理は既存構造を再利用した。
- 学籍番号入力は学部・大学院U/M/Dと全64所属コードに対応した。
- 履修候補理由・判定理由を授業カードへ追加していない。
- 保存時は所属コード・入学年度・実学年・追加属性を保持し、学籍番号全体を保存しない。
- 学籍番号解析後、対象学生に意味のある追加属性だけを生成マスターから表示する。
- ON/OFFは複数選択、コース・専修・第一言語は単一選択とし、選択状態を既存UIへ合わせた。
- Web実行時は生成済みJSONだけを読み、PDF/XLSXを解析しない。
- 授業詳細を開くと、`授業一覧.csv` の時間割コードが一致する公式シラバスURLを表示する。
- URL対応表は詳細を初めて開いた時だけ静的JSONから読み込み、6,298件をアプリ本体へ重複して埋め込まない。
- URLは `https://cssy.aasa.ac.jp` のみを表示対象とし、別タブを開くリンクには `noopener noreferrer` を設定した。
- 月〜金の1〜7限・11〜14限を選択可能にし、複数曜日授業は全該当コマを使用する。
- 集中・曜日時限未定418クラスは専用選択で検索・登録でき、通常時間割外として表示する。
- 希望タグは正式Excelの授業系統10分類へ合わせ、同じ評価軸の矛盾するタグは同時選択しない。
- 同一曜日時限の授業重複を、通常一覧・名前検索・最終追加処理のすべてで防止する。
- おすすめ一覧と登録済み授業で共通のシラバス詳細・公式URLを表示する。
- モーダルへダイアログ属性、Esc操作、フォーカス移動・フォーカストラップを追加した。
- 大容量マスターは初期JavaScriptへ含めず、結果画面で静的JSONから読み込みPWAキャッシュへ保存する。

型検査とlintを通過したため、PHASE 5へ進んだ。
