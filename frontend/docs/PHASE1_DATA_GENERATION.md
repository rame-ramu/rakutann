# PHASE 1: 2026 初期データ生成記録

## 入力の限定

`2026 初期データー　ベータ版/` にある次の9ファイルだけを正式入力として使用する。生成時には各ファイルの SHA-256 を `data/generated/generation_metadata.json` に保存する。

- `summary_2026.pdf`
- `summary_2025.pdf`
- `summary_change_2025_0325.pdf`
- `summary_2024.pdf`
- `summary_graduate_2026.pdf`
- `summary_graduate_2025.pdf`
- `summary_graduate_change_2025.pdf`
- `summary_graduate_2024.pdf`
- `syllabus_analysis_2026.xlsx`

依頼文のファイル名に付いていた `(1)`、`(2)`、`(3)` はアップロード時の重複名サフィックスであり、ワークスペース上の実ファイル名には含まれていない。

旧CSV、旧JSON、旧Excel、既存の `src/data/courses.ts` は履修・授業データの生成元として参照しない。

### シラバスURLの補助入力

追加指定された `授業一覧.csv` は、授業詳細画面へ公式シラバスURLを表示する目的だけで使用する。履修可否、所属、年次、推薦タグ、授業内容の判定元には使用しない。

CSVの `時間割コード` を正式Excel由来のクラスID（`2026_時間割コード`）へ完全一致させる。科目名だけのJOINは行わず、完全一致した後の整合性検査として科目名も比較する。

## 実行方法

```sh
npm run generate:data
```

実行時にPDFを座標付きで解析し、2026年度Excelは `course_id` の6桁基本科目番号とクラス番号へ分離する。Webアプリ実行時にはPDF・Excelを解析しない。

## 2025年度変更表の適用

- `106011 日本語III`、`106012 日本語IV`、`106013 キャリア日本語I`、`106014 キャリア日本語II` を追加した。
- 変更後欄に単位数、履修年次、開講学期がないため、上記4科目は削除せず `conditional` とした。
- `291067 食品加工学実習` のナンバリングを `2420` へ上書きした。
- 上記日本語4科目の卒業要件単位に算入しない注記を記録した。これは履修候補からの除外条件にはしていない。
- 大学院2025年度変更表のGPA制度変更を記録した。科目の所属・履修年次を変える変更ではないため、候補フィルタは変更していない。

## 推測せず残した事項

- 履修要覧は「他学部・他学科開放科目一覧」を3月下旬にCampusSquareへ別途掲載すると記載している。正式9ファイルには科目番号一覧がないため、`open_courses_master.json` は空配列とし、欠損を `generation_issues.json` に記録した。
- `CLD` の「図書館情報学領域」は、指定された正式大学院資料内で研究科階層を一意に確定できない。専修名とD課程は保持し、研究科・専攻は `null` のまま記録した。
- 廃止済み読替元 `110009 Central Japan` はPDFに履修年次が記載されていない2レコードがある。読替先 `110019` を保持し、元レコードは `conditional` とした。
- 引用された前提・関連科目名が履修表の科目名と完全一致せず、科目番号へ一意に解決できない関係は未解決として記録した。
- 同一の共通科目が複数専攻の表へ重複掲載される場合、1件へ正規化し、すべての掲載元を保持した。
