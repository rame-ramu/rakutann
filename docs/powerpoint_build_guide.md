# PowerPoint作成ガイド

「らくたんん!!」の発表スライドを作るための指示書です。  
基本は **10枚構成** で作ってください。

## 1枚目: タイトル

スライドに書くこと:

> らくたんん!!  
> 疲れたあなたに、ちょうどいい履修を。  
> 人間情報学部向け 履修支援Webアプリ

載せるもの:

- アプリのトップ画面
- 発表者名、チーム名、日付

話すこと:

> 履修登録で授業を探す手間を減らすためのWebアプリを作りました。

## 2枚目: 背景・課題

スライドに書くこと:

> 履修登録では、授業を選ぶまでに時間がかかる。

- シラバスの情報量が多い
- 評価方法を比較しにくい
- 空きコマと授業を照合するのが面倒
- 自分に合う授業を探しにくい

載せるもの:

- シラバスや時間割のイメージ画像
- 画像がなければ、困りごとを4つの枠で表示

話すこと:

> レポートの多さ、試験の有無、オンデマンド回数などを1科目ずつ確認するのは大変です。

## 3枚目: アプリ概要

スライドに書くこと:

> 学籍番号・希望条件・空きコマから、おすすめ授業を表示するアプリ。

できること:

- 学部・学年を自動判定
- 条件タグで授業を検索
- 空きコマに合う授業を表示
- 授業詳細と推薦理由を確認
- 候補授業を時間割に登録

載せるもの:

- アプリ画面を1枚大きく載せる
- 可能なら「入力 -> 結果」の簡単な図

話すこと:

> ユーザーは条件を選ぶだけで、自分に合いそうな授業を探せます。

## 4枚目: 操作フロー

スライドに書くこと:

> 4ステップで授業を探せる。

1. 学籍番号を入力
2. 希望条件を選択
3. 空きコマを選択
4. おすすめ授業を確認

載せるもの:

- 4つの画面スクリーンショット
- 矢印で `入力 -> 条件 -> 時間割 -> 結果` とつなぐ

話すこと:

> 操作の流れを4ステップにして、迷わず使えるようにしました。

## 5枚目: 学籍番号入力

スライドに書くこと:

> 学籍番号から学部・学年を自動で判定する。

- 入力例: `24XXXNKU01`
- 学部コードから所属を判定
- 入学年度から学年を計算
- 対象外の学部にはメッセージを表示

載せるもの:

- 学籍番号入力画面
- 判定結果が表示された画面

話すこと:

> 最初に学籍番号を入れることで、その学生に合う授業だけを探しやすくしています。

## 6枚目: 条件選択

スライドに書くこと:

> 授業の特徴をタグで選べる。

選べる条件:

- 成績評価: レポート、試験、出席点
- 授業形態: オンデマンド、前提履修
- 系統: 情報・データ、心理・人間など
- 除外条件: 受けたくない先生

載せるもの:

- 条件タグを選んだ画面
- 選択中のタグを赤枠で強調

話すこと:

> 「試験なし」「オンデマンド多め」など、学生が気にしやすい条件で探せます。

## 7枚目: 推薦の仕組み

スライドに書くこと:

> 条件に合う授業だけを絞り込み、一致数が多い順に表示する。

流れ:

1. 学年に合う授業に絞る
2. 学期に合う授業に絞る
3. 空きコマに合う授業に絞る
4. 除外した先生を外す
5. 希望タグの一致数で並べる

載せるもの:

- 絞り込みの流れを図にしたもの
- 結果一覧の「希望タグ◯件一致」が見える画面

話すこと:

> 複雑なAIではなく、条件に基づいて理由が分かる推薦にしています。

## 8枚目: 結果・詳細画面

スライドに書くこと:

> 授業の内容と、おすすめされた理由を確認できる。

表示する情報:

- 授業名、担当教員、曜日時限
- レポート、試験、出席の割合
- オンデマンド割合
- 授業タグ
- タグが付いた理由

載せるもの:

- 結果一覧画面
- 授業詳細画面
- 「タグが付いた理由」の部分を拡大

話すこと:

> 一覧だけでなく詳細も見られるので、納得して授業を選べます。

## 9枚目: 時間割登録・デモ

スライドに書くこと:

> 候補に入れた授業を時間割に反映できる。

デモで見せる流れ:

1. 学籍番号を入力
2. 条件を選ぶ
3. 空きコマを選ぶ
4. 結果を見る
5. 授業を候補に追加
6. 時間割に反映

載せるもの:

- デモ動画
- 候補授業が入った時間割画面

話すこと:

> 授業を探して終わりではなく、時間割として確認できるところまで作りました。

## 10枚目: まとめ・今後の改善

スライドに書くこと:

> 履修登録の「探す・比べる・組む」を楽にするアプリを作った。

まとめ:

- 学籍番号から学部・学年を判定
- 条件タグで授業を検索
- 空きコマに合う授業を推薦
- 推薦理由を表示
- 候補授業を時間割に登録

今後の改善:

- 対象学部を増やす
- 必修科目や単位数チェックを追加
- 時間割共有機能を追加
- データ更新を自動化

載せるもの:

- トップ画面、結果一覧、時間割画面を小さく3枚並べる

話すこと:

> 今後は対象範囲を広げて、履修計画全体を支援できるアプリにしていきたいです。

## 作るときの注意

- 1枚の文字量は少なめにする
- スクリーンショットは大きく載せる
- 学籍番号などの個人情報は架空のものを使う
- デモ動画は60〜90秒にする
- 色はアプリに合わせて白・黒・黄色・緑を中心にする
