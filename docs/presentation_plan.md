# 「らくたんん!!」発表スライド案

## 発表の軸

このプロジェクトは「履修登録で悩む時間を減らし、自分に合う授業を探しやすくするWebアプリ」として説明すると伝わりやすいです。

中心メッセージ:

> 学籍番号から対象学生を判定し、希望条件と空きコマに合わせて、人間情報学部向けの授業候補を推薦するアプリを作りました。

強調するポイント:

- 履修登録時の「シラバスを読む量が多い」「評価方法を比較しづらい」「時間割と照合するのが面倒」という課題に向けたアプリ
- 学籍番号、希望条件、空きコマの3つを入力するだけで候補を絞り込める
- 授業ごとに「なぜ推薦されたか」をタグと理由で表示できる
- 候補に入れた授業を時間割上に登録できる

## 推奨スライド構成

### 1. タイトル

タイトル:

> らくたんん!!  
> 疲れたあなたに、ちょうどいい履修を。

本文:

> 人間情報学部向けの履修支援Webアプリ  
> 学籍番号・希望条件・空きコマから、おすすめ授業を探せる

載せる素材:

- アプリのトップ画面スクリーンショット
- 可能ならスマホ表示のスクリーンショットも横に小さく配置

話す内容:

> 履修登録のときに、シラバスを1つずつ開いて評価方法や曜日時限を確認するのは手間がかかります。そこで、自分の条件に合う授業を簡単に探せるアプリを作りました。

### 2. 背景と課題

タイトル:

> 履修登録で困ること

本文:

- シラバスの情報量が多く、比較に時間がかかる
- レポート、試験、出席、オンデマンドなどの条件を横断的に探しにくい
- 空きコマと授業候補を手作業で照合する必要がある
- 自分の学年や学部に合う授業か確認する手間がある

載せる素材:

- シラバス画面、履修登録画面、時間割表の写真やスクリーンショット
- 個人情報が写る場合は必ずぼかす

話す内容:

> 特に、評価方法やオンデマンド回数のような情報は、1科目ずつ確認しないと分かりにくいです。このアプリでは、それらを条件タグとして整理し、探しやすくしました。

### 3. 解決策

タイトル:

> 条件に合う授業を自動で絞り込む

本文:

> 「らくたんん!!」は、学籍番号から学部・学年を判定し、希望条件と空きコマに合う授業を一覧で表示します。

主な機能:

- 学籍番号から学部・学年を判定
- 前期・後期を選択
- レポート重視、試験なし、オンデマンド多めなどの条件で検索
- 受けたくない先生を除外
- 空きコマに合う授業だけを表示
- 候補授業を時間割に登録

載せる素材:

- 4画面の操作フロー画像  
  `学籍番号入力 -> 条件選択 -> 空きコマ選択 -> 結果一覧`

話す内容:

> ユーザーは難しい検索式を入力する必要はありません。ボタンを選んでいくだけで、条件に合う授業候補が出るようにしています。

### 4. 操作フロー

タイトル:

> 4ステップで授業を探す

本文:

1. 学籍番号を入力する
2. 授業の希望条件を選ぶ
3. 授業を入れたい曜日・時限を選ぶ
4. おすすめ授業から候補を選ぶ

載せる素材:

- 各ステップのスクリーンショットを横並び、または2x2で配置
- 画面上の `Step 1 / 4` から `Step 4 / 4` が見えるように撮る

話す内容:

> 入力の流れを固定しているので、履修に詳しくない人でも迷いにくい構成にしました。戻る、次へボタンも用意し、条件を変更しながら探せます。

### 5. 入力できる条件

タイトル:

> 授業の特徴をタグで選べる

本文:

条件カテゴリ:

- 成績評価: レポート・課題、試験、出席点
- 授業形態: オンデマンド、前提履修
- 系統: 情報・データ、心理・人間、ビジネス・経営など
- その他: 受けたくない先生の除外

載せる素材:

- 条件選択画面のスクリーンショット
- 選択中タグが分かる状態で撮る

話す内容:

> 「試験なし」「レポート重視」のような学生が実際に気にする条件をタグ化しました。授業の専門分野だけでなく、評価方法でも選べるところが特徴です。

### 6. 使用データ

タイトル:

> シラバスデータを検索しやすい形に変換

本文:

- 授業データ数: 378件
- 対象: 人間情報学部向けの授業データ
- 元データ: Excelのシラバス情報
- 変換後: アプリ内で扱いやすい授業データ
- 各授業に評価割合、曜日時限、オンデマンド回数、前提履修、分類タグを付与

データ例:

| 項目 | 例 |
| --- | --- |
| 評価 | レポート40%、試験45%、出席15% |
| 授業形態 | 対面授業、オンデマンド少なめ |
| 曜日時限 | 火3限 |
| タグ | #試験あり #出席点低め #情報・データ |

載せる素材:

- Excelデータの一部をぼかして載せる
- アプリ内の授業詳細モーダルのスクリーンショット

話す内容:

> シラバス情報をそのまま見せるのではなく、条件検索しやすいデータに変換しています。発表では、元のExcelからアプリ表示に変わる流れを見せると説得力が出ます。

### 7. 推薦の仕組み

タイトル:

> 条件一致数と空きコマでおすすめ順に並べる

本文:

推薦の流れ:

1. 学年に合う授業だけに絞る
2. 選んだ学期に合う授業だけに絞る
3. 選んだ曜日・時限に合う授業だけに絞る
4. 除外した先生を含む授業を外す
5. 希望タグの一致数が多い順に並べる

スコアの考え方:

> 希望タグの一致数を重視し、さらに選択した空きコマと合う授業を表示する。

載せる素材:

- 簡単な処理フロー図
- 結果一覧で「希望タグ 3件一致」のような表示が見えるスクリーンショット

話す内容:

> このアプリは完全なAI推薦ではなく、条件に基づいた分かりやすい推薦です。なぜ表示されたのかをユーザーが理解できることを重視しました。

### 8. 結果表示と詳細画面

タイトル:

> なぜおすすめされたかが分かる

本文:

- 授業名、担当教員、曜日時限を一覧表示
- レポート、試験、出席、オンデマンド割合を表示
- 希望条件に合ったタグを表示
- 詳細画面でタグが付いた理由を確認可能
- 気になる授業は候補に追加できる

載せる素材:

- 結果一覧画面
- 授業詳細モーダル
- 「タグが付いた理由」の部分を拡大したスクリーンショット

話す内容:

> ただ授業を並べるだけでなく、評価割合やタグの理由まで見られるようにしています。これにより、ユーザーが納得して候補を選べます。

### 9. 時間割登録

タイトル:

> 候補授業を時間割に反映

本文:

- 候補に追加した授業が時間割上に表示される
- 同じ曜日・時限の重複を防ぐ
- 登録済み授業を解除できる
- 長押しで教室番号も登録できる

載せる素材:

- 時間割画面のスクリーンショット
- 候補授業がマスに入っている状態
- 教室番号を入れた状態

話す内容:

> 授業を探して終わりではなく、実際の時間割として確認できるところまで作りました。候補を追加すると、そのコマはロックされ、重複登録しにくくしています。

### 10. デモ

タイトル:

> デモ: 条件から授業を探す

デモ手順:

1. トップ画面で学籍番号例 `24XXXNKU01` を入力
2. 「人間情報学部 感性工学専攻 3年生」のように判定されることを見せる
3. 前期または後期を選ぶ
4. 条件タグを選ぶ  
   例: `試験なし`、`オンデマンド多め`、`情報・データ`
5. 空きコマを複数選ぶ
6. 結果一覧を表示
7. 授業詳細を開き、評価割合とタグ理由を見る
8. 候補に追加
9. 時間割に反映されることを確認

動画で撮る場合:

- 60秒から90秒に収める
- マウス操作はゆっくり
- 入力する学籍番号は架空のものを使う
- 個人情報、大学システムのログイン画面、実在学生の情報は映さない

話す内容:

> 実際に、学籍番号入力から授業候補の登録までを流します。条件を変えると結果も変わるので、単なる一覧表ではなく、ユーザーに合わせて絞り込んでいることが分かります。

### 11. 工夫した点

タイトル:

> 工夫した点

本文:

- 難しい検索フォームではなく、タグボタン中心の操作にした
- 学籍番号から学部・学年を自動判定するようにした
- 推薦理由をタグとして見える化した
- スマホでも使いやすいようにレスポンシブ対応した
- 漫画風の太い枠線と影で、堅くなりすぎないデザインにした

載せる素材:

- PC表示とスマホ表示を並べる
- タグ選択画面と詳細画面の一部を拡大

話す内容:

> 履修登録は面倒な作業になりがちなので、見た目も少し親しみやすくしました。一方で、評価割合や条件の根拠はきちんと見られるようにしています。

### 12. 課題と今後の改善

タイトル:

> 今後の改善

本文:

- 対象学部を人間情報学部以外にも広げる
- 実際の履修登録システムとの連携を検討する
- 単位数の合計や必修科目チェックを追加する
- 友人との時間割共有機能を追加する
- ユーザー評価をもとに推薦精度を改善する
- データ更新を自動化する

載せる素材:

- 今後追加したい機能をアイコンや簡単な図で表示
- 「現在」と「今後」の比較表

話す内容:

> 現在は条件検索と候補登録が中心です。今後は、必修科目や単位数の管理まで含めることで、履修計画全体を支援できるアプリにしたいです。

## 写真・スクリーンショットの撮影リスト

必ず撮る:

- トップ画面
- 学籍番号を入力して学部・学年が判定された画面
- 条件タグを複数選択した画面
- 空きコマを選択した時間割画面
- 結果一覧画面
- 授業詳細モーダル
- 候補授業を時間割に登録した画面

あるとよい:

- Excelの元データ
- PC表示とスマホ表示の比較
- 条件を変える前後の結果一覧
- 対応していない学部を入力したときのメッセージ

撮影時の注意:

- 学籍番号は架空のものを使う
- 個人情報やログイン情報は映さない
- 画面を拡大しすぎず、アプリ全体の流れが分かるように撮る
- PowerPointに貼る写真は、文字が読める解像度で撮る

## デモ動画の構成案

動画タイトル:

> らくたんん!! 操作デモ

尺:

> 60秒から90秒

構成:

| 秒数 | 内容 |
| --- | --- |
| 0-10秒 | トップ画面、学籍番号入力 |
| 10-25秒 | 条件タグと学期を選択 |
| 25-40秒 | 空きコマを選択 |
| 40-60秒 | 結果一覧を確認 |
| 60-75秒 | 授業詳細で推薦理由を見る |
| 75-90秒 | 候補追加、時間割反映 |

字幕案:

- 学籍番号から学部・学年を自動判定
- 希望条件をタグで選択
- 空きコマに合う授業だけを表示
- 評価割合と推薦理由を確認
- 候補授業を時間割に登録

## スライドデザイン方針

- アプリの色に合わせて、白、黒、黄色、緑を中心にする
- 1枚に文章を詰めすぎない
- 各スライドは「見出し1つ、要点3つ、画像1つ」を基本にする
- デモ画面は大きく載せる
- 説明文より、スクリーンショット上に赤枠や吹き出しを付けるほうが伝わりやすい

## そのまま使える短い紹介文

> 「らくたんん!!」は、人間情報学部の学生向けに、履修登録を支援するWebアプリです。学籍番号から学部・学年を判定し、希望する評価方法や授業形態、空きコマに合わせて授業候補を表示します。授業ごとに評価割合や推薦理由を確認でき、候補に入れた授業は時間割に反映できます。
